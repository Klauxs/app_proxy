# IFEO 取消决定

2026-09-20，用户明确决定“不做 IFEO”。本章替代此前的设计草案和保留方向，IFEO 不再属于产品范围、待开发项或发布验收门槛。此前设计可在 Git 历史中查阅。

已移除 IFEO 注册、归属恢复 journal、入口/命令行解析、调试创建脱离及对应实验命令。原版 Guard 不再等待 IFEO，就绪标准与分身一致：经验证的 ETW 监听、新鲜扫描、无归属冲突或未决纠正。授权、心跳、扫描过期和轮询降级仍按实际证据判断。

本工具入口先准备代理再启动应用；系统原始入口保持原有行为。Guard 在进程创建之后检查，外部误启动可能在被识别和纠正前已经执行或联网，不保证首次联网前阻断。未管理原版继续不干预。

只读 `creation_guard` 保留对系统既有 Debugger 重定向的检查，发现时返回 `EXTERNAL_DEBUGGER_UNSUPPORTED`，不修改或绕过注册。配置中 `integrations.ifeo` 仅保留固定空数组，以保持已有配置事务摘要；非空旧登记明确拒绝，不能静默删除记录或系统规则。本次未修改真实应用的机器级注册。

Guard 状态删除 IFEO 字段、启动来源删除 Ifeo，因此 coordinator IPC 使用 major 3，保留现有 minor 19 操作门槛。旧 major 在握手时拒绝；CLI、host 与 coordinator 需成套更新。
