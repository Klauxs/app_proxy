# 安装与升级

所有正式文件集中在 `%USERPROFILE%\AppProxy`：`app` 存放前后台 EXE；`data` 存放配置、订阅、代理内核、状态及 `instances` 分身数据；`resources` 保存跨 store 的资源占用记录；`guard` 按用户/store/generation 保存管理员监听组件。根路径使用 Windows Profile Known Folder，不接受环境变量冒充。监听子目录保留现有 ACL，不修改用户目录或其他子目录的权限。不移动已有开发版目录或导入旧工具数据。

主目录刻意放在 AppData 外，避免 MSIX 的 AppData 重定向使普通进程、包内辅助进程和 Explorer 看到不同物理文件。正式布局下 MSIX 分身与启动通信文件同样存放在 `data`，不再分散到 `Packages\...\LocalState`。显式开发 `--home` 位于正式布局之外时，启用虚拟化的包仍使用原有 LocalState 路径；这不是旧版迁移。

## 运行中升级

安装器取得发行目录的独占维护租约后，前台拒绝新命令，协调进程每 250ms 检查一次维护信号。协调进程先撤销 Guard 新工作，再等待已接受的请求、启动和代理操作结束，然后退出；已经运行的应用与 sing-box 不会被关闭。监听连接结束后退出。租约由 Windows 文件共享约束实现，安装器崩溃会释放信号；残留空文件不代表仍在升级。

安装器还要确认两个程序及备份文件不再占用才替换。仍在菜单等待输入时，需要用户退出菜单；等待最多 60 秒后报告占用，不按进程名强杀。协调进程退出后，新版本会从既有精确身份记录接续共享代理。

## 监听组件更新

普通 `guard enable` 仍不覆盖不同发行版本。安装器通过新前台的受限 `setup-prepare` 入口，固定同目录 host 的身份、大小和 SHA-256，并把现有监听 generation 绑定进 UAC 参数。提权端只复制自身映像，不接受任意安装路径或可写命令脚本。

提权端先创建和核验新 generation、保存更新意图，再核验并停止/移除旧事件任务、切换受保护登记并注册新任务。旧 generation 保留。中断后重用已准备的 generation；来源、任务或登记不匹配时保留现场，拒绝覆盖。UAC 取消不回滚已发布的程序；重新运行同一安装包继续完成组件配置。

新前台在离线持有 store 时完成登录入口核验/登记，再解除维护信号，通过 `setup-verify` 启动协调进程并等待已启用保护实例的 ETW 接入。普通登录入口和桌面实例入口继续使用固定程序路径。

## 单文件发行

运行 `rust/scripts/package.ps1` 构建。脚本在 `rust/target/package` 保存中间编译产物，避免覆盖正在运行的开发版，最终只分发 `rust/target/release/AppProxy-Setup.exe`。Setup 内嵌同批构建的前台和后台 EXE 及 SHA-256，使用静态 VC 运行库，无需用户安装 Rust、编译工具或另外下载两个 EXE。发行包不包含 sing-box，首次需要时沿用程序内的安装流程。

Setup 带 `asInvoker` manifest，普通用户双击运行；不会因 Setup 文件名触发整个安装器自动提权。安装前显示版本、固定位置及对运行后台的影响；原生进度窗口显示退出等待、组件配置和核验阶段。安装成功创建当前用户桌面和开始菜单的 `AppProxy` 入口；升级时复用匹配入口，缺失时补建，不覆盖同名的其他快捷方式，可选择立即打开。每次安装日志写入 `%TEMP%/AppProxy-setup-*.log`，错误窗口提供完整路径。`--yes --no-launch` 用于无交互安装；它不会跳过 Windows 的 UAC 授权。

只维护已登记安装中的两个固定 EXE。目标目录已有陌生文件、已登记 EXE 被修改、链接被修改或配置根不属于当前格式时拒绝覆盖。安装记录 `.app-proxy-install.json` 绑定文件哈希；`.app-proxy-upgrade.json` 保存旧、新记录及发布阶段。两个文件替换期间的失败恢复已核验的旧副本；已发布新版本后保留待完成记录，允许同一安装包继续授权/核验，避免反复替换文件身份。更新中断留下半套程序时，启动入口即使在安装器已退出后也拒绝启动。只有明确发布完成的程序对才能启动后续核验。

安装器持有独立事务锁直到全部核验完成；解除后台维护信号后，第二个 Setup 仍不能进入。清理仅处理本次记录的备份文件，不清理应用、配置、订阅、实例数据或任意旧目录。Windows 原始应用快捷方式不接管，已登记实例桌面入口因路径固定而保留。

## 范围

- 支持固定目录首次安装及同目录升级/重试，不自动检查或下载 AppProxy 新版本；升级时运行新的 Setup。
- 不导入旧脚本版或 `AppProxyRust` 开发版，不做跨目录迁移。旧 AppData 目录不再影响新安装；只有新的 `data` 目录存在未知内容时才报告冲突并保留全部内容。
- 安装/升级针对默认数据根；开发用 `--home` 数据根不由正式安装器批量维护。
- 本地生成的包尚未做 Authenticode 代码签名；哈希用于包内完整性和安装归属核验，不是发行者签名。
- 目前不提供卸载向导；不要把本文件的升级恢复机制理解为旧产品迁移或完整卸载。
