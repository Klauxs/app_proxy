# 安装与升级

正式目录固定为 `%LOCALAPPDATA%\Programs\AppProxy`，配置为 `%LOCALAPPDATA%\AppProxy`。受保护监听组件仍按用户/store/generation 分代安装到 `%ProgramFiles%\AppProxy\Guard`。不移动已有开发版目录或导入旧工具数据。

## 运行中升级

安装器取得发行目录的独占维护租约后，前台拒绝新命令，协调进程每 250ms 检查一次维护信号。协调进程先撤销 Guard 新工作，再等待已接受的请求、启动和代理操作结束，然后退出；已经运行的应用与 sing-box 不会被关闭。监听连接结束后退出。租约由 Windows 文件共享约束实现，安装器崩溃会释放信号；残留空文件不代表仍在升级。

安装器还要确认两个程序及备份文件不再占用才替换。仍在菜单等待输入时，需要用户退出菜单；等待最多 60 秒后报告占用，不按进程名强杀。协调进程退出后，新版本会从既有精确身份记录接续共享代理。

## 监听组件更新

普通 `guard enable` 仍不覆盖不同发行版本。安装器通过新前台的受限 `setup-prepare` 入口，固定同目录 host 的身份、大小和 SHA-256，并把现有监听 generation 绑定进 UAC 参数。提权端只复制自身映像，不接受任意安装路径或可写命令脚本。

提权端先创建和核验新 generation、保存更新意图，再核验并停止/移除旧事件任务、切换受保护登记并注册新任务。旧 generation 保留。中断后重用已准备的 generation；来源、任务或登记不匹配时保留现场，拒绝覆盖。UAC 取消不回滚已发布的程序；重新运行同一安装包继续完成组件配置。

新前台在离线持有 store 时完成登录入口核验/登记，再解除维护信号，通过 `setup-verify` 启动协调进程并等待已启用保护实例的 ETW 接入。普通登录入口和桌面实例入口继续使用固定程序路径。
