# 创建实例时自动创建桌面入口

此前菜单保存实例后直接进入保护授权和启动确认，桌面快捷方式需要另到管理菜单手动创建，导致重装后添加实例没有入口。

添加实例、复制配置创建空白分身现在都在保存后自动调用现有快捷方式服务，再进入保护和启动步骤。原版使用应用名及原应用图标；分身沿用已有独立命名规则。返回启动确认、取消后续授权均不撤销已保存的入口。快捷方式提交会增加配置版本，因此保护启用前重新读取配置版本。

创建入口失败会显示现有服务提供的原因，保留实例并提示从“管理实例 → 桌面快捷方式”重试，仍继续保护流程。同名非本工具文件不会被覆盖。CLI 的配置创建命令保持原有职责；此次调整的是日常交互菜单。

验证：菜单单元测试 4 项、快捷方式 CLI 合约 3 项通过，Clippy all-targets 和格式检查通过。使用独立临时数据目录，在真实终端菜单添加测试实例：桌面入口自动生成，拒绝启动并退出后原生核验为 verified，Windows Shell 可枚举该入口。另以同名测试文件验证冲突提示、文件不被覆盖和实例仍保存；测试入口和冲突文件已清理。未启动测试应用，也未重启正式 Claude。
