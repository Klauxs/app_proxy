# Guard 逐事件原生读取：2026-09-20

## 实现

已将 ETW 事件的纠正路径改为逐个 PID/CreateTime 处理。普通协调进程打开目标并保留同一个进程句柄，以 `NtQueryInformationProcess(ProcessCommandLineInformation)` 读取命令行，再验证确切映像、用户、会话、实例数据目录与代理参数。读取失败或归属不明不授权关闭。

事件创建时间与原生进程身份不一致时忽略事件；事件中的映像短名不作为控制权限依据。命令行读取至终止不重新按 PID 打开进程，不扫描同名候选，不等待 WMI。实例登记、资源预留、配置/取消校验和持久停止许可保持不变。停止通过原保留句柄执行，目标自行退出则不会关闭其他进程。

主进程关闭后才检查占用及残留辅助进程，最多等待 3 秒；未确认清空时不重启，也不批量终止子进程。代理失败仍保持关闭，不回退直连。后台初始扫描、丢事件补扫、周期补扫和重启前占用检查仍可使用 WMI。

事件管道升级为 v2，新增必填 CreateTime；普通事件队列上限 256，PID/创建时间去重，溢出请求完整补扫。旧授权撤销及服务结束会清空排队事件。
