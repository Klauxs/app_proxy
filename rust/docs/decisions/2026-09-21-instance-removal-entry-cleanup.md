# 实例移除自动清理桌面入口

此前创建实例已自动创建桌面快捷方式，但“移除登记”直接提交配置删除。底层为避免留下无法追踪的入口，返回 `INTEGRATION_CLEANUP_REQUIRED`，因此实例没有被移除；菜单只显示错误码，用户无法判断原因。

现在移除确认明确包含实例登记及桌面快捷方式。菜单按已有所有权记录清理本实例的入口，获取新的配置版本后再移除实例。已中断的入口删除沿用原请求恢复，未完成的创建可以取消；未完成的恢复操作要求先在入口管理中处理。文件被修改等冲突保留实例和文件，并明确显示“实例尚未移除”。底层清理前置条件不变，CLI 拒绝提示也改为中文。

移除不关闭应用，不删除应用数据，也不删除其他实例共用的监听和登录任务。本次未替用户选择或移除正式 Claude/Codex 实例。

验证：快捷方式 CLI 合约 3 项、Clippy all-targets、格式和差异检查通过。在真实交互终端使用独立测试实例验证：修改过的链接导致移除中止，实例与链接内容均保留；恢复测试文件后再次移除，沿原删除请求完成，实例列表为空，桌面链接不存在，数据标记仍保留。测试未启动目标应用。
