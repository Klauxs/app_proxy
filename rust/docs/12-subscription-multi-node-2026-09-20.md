# 订阅默认流程、地区分组与自动选节点

2026-09-20。本次是订阅配置功能更新，不修改 Guard 的 20 ms 设置。

## 使用

菜单“代理配置 → 添加代理（订阅）”直接输入订阅地址，默认直连下载，不再询问代理类型、下载方式或名称。新名称使用“订阅标题 · 地区 · 本地时间”，例如“示例订阅 · 台湾 · 20260920-2130”。标题优先使用下载响应中的 `profile-title`（支持 Base64）或 `Content-Disposition` 文件名，缺失或不适合作为显示名时使用订阅域名，不采用地址路径或查询参数。多地区显示地区组合，重复名称加“（2）”等序号；已有名称保持不变，管理中的“改名”仍可使用。手动 HTTP/SOCKS5 是代理配置菜单的独立入口。

选择后的正常成功提示只显示名称、已选节点数和模式，不再枚举所有新增节点、不显示内部 UUID 或版本。刷新只显示新增/移除数量。结果未确认时仍提供原请求查询编号，CLI 的 JSON 输出仍保留完整结构化回执。

节点按名称中的地区、英文别名或旗帜分组，无法识别的放入“其他 / 未识别”。这是名称提示，不查询 IP 所在地。节点编号沿用订阅顺序，在地区内显示；可以输入：

- `1,3-5`：多个节点，也可用中文逗号。
- `G1,G3`：两个地区组中的全部节点，可与节点编号混合。
- `all`：所有节点。
- `0` 或回车：取消，保留原配置。

单选仍使用固定节点，多选由 sing-box `urltest` 在所选节点中自动测速选择。正式配置使用设置里的 HTTPS 测试地址、3 分钟间隔、50 ms 容差，不主动中断已有连接。首次测试完成前不保证已选到最快节点；故障检测也不是即时的。没有直连兜底。

订阅刷新只保留仍存在的已选节点，不自动加入新节点；剩一个时转为固定节点，已选节点全部消失时拒绝刷新并保留旧配置。活动代理的配置切换仍使用既有共享内核影响预览与确认。多选候选信息进入持久配置、启动依赖判断和共享内核切换恢复日志，摘要显示候选数量，不把第一个候选称为当前出口。

CLI 也支持省略名称和多选：

```powershell
app-proxy.exe proxy import
app-proxy.exe proxy import --url-stdin --node "HK-A" --node "JP-B" --json
app-proxy.exe proxy select <代理ID> <节点ID1> <节点ID2> --json
```

地址仍通过不回显输入或标准输入提供。命令行 `--via` 保留为显式代理下载选项。显示标题的预览协议更新为 IPC 3.22，菜单、CLI、host 应成套使用；旧协调进程不能处理新的订阅预览协议。
